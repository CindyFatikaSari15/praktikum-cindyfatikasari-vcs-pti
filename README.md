# praktikum-cindyfatikasari-vcs-pti
Latihan Version Control System mahasiswa PTI
Repository ini dibuat untuk memenuhi kegiatan Praktikum Administrasi Digital pada materi Version Control System (VCS).

## Deskripsi
Praktikum ini bertujuan untuk mengenal penggunaan GitHub sebagai platform untuk menyimpan, mengelola, dan mendokumentasikan perubahan file dalam sebuah proyek.

## Tujuan Praktikum
- Memahami fungsi repository pada GitHub.
- Mempelajari cara membuat dan mengelola repository.
- Mengenal file README.md sebagai dokumentasi proyek.
- Memahami penggunaan commit untuk menyimpan riwayat perubahan.

## Identitas
- Program Studi: Pendidikan Teknologi Informasi
- Universitas: Universitas Lampung

## Penutup
Repository ini merupakan bagian dari proses pembelajaran penggunaan GitHub dan penerapan Version Control System.
